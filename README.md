TorqueX

Nombre y apellido: Rodrigo Bustamante

Descripción del proyecto

TorqueX es una aplicación web de comercio electrónico orientada a la venta de repuestos y accesorios para vehículos.

En esta primera etapa del proyecto se desarrolló la estructura general de la aplicación utilizando HTML. La página cuenta con una página de inicio, navegación entre las diferentes categorías de productos, una página de inicio de sesión y una página de registro de usuarios.

Las categorías disponibles son:

Motor
Frenos
Suspensión
Accesorios
